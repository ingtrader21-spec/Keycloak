# Observability

`config/observability/keycloak-alerts.yaml` is a vendor-neutral Prometheus rule contract for readiness, database health, restart loops, server errors, request latency, login/token/SMTP/admin failures, brute-force lockouts, stale backups, failed reconciliation, GitOps drift, certificate expiry and disk pressure. Deployment owners must bind the contract metric names to the installed Keycloak, PostgreSQL, blackbox, host and GitOps exporters. Logs must redact authorization headers, tokens and credentials. Alert routing is a production-environment responsibility and remains unverified until exercised.
